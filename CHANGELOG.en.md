# Changelog

**🇬🇧 English** · [🇨🇿 Česky](CHANGELOG.cz.md)

## 0.2.0a2 — 2026-09-20 (public alpha)

- First public source snapshot under netiqus, with a separate public history.
- Updated project motivation, related approaches, methodology and contribution invitation in English and Czech.
- Public installation instructions and current release archives. Gate behaviour and default thresholds are unchanged from 0.2.0a1.

## 0.2.0a1 — 2026-09-20 (alpha draft)

- Prepared under netiqus: English-first onboarding, public agent integration brief, clean-export CI and installable alpha archives.

- Czech questions and definitions for both news presets, explicit preset-language selection and localized criterion labels. Interface switching preserves custom drafts and historical wording.

- Local bilingual article/policy editor with explicit methodology, editable criteria, free request inspection, immutable run snapshots and policy export. Reports render saved policies instead of the current preset.
- A closing note in the news example explores translation as a possible additional framing layer; EN/CZ observations are separated from claims of translation quality.
- English-first public entry points, an MIT licence in all distributions, and an explicit credential-integration guide.

- Bilingual README and documentation with counterpart links and local-link validation.
- News example: two extended fictional articles in EN/CZ, five features, a legend and author annotations.
- Model-free preview and two optional live checks with local HTML/JSON reports and accounting.

## 0.1.0 — 2026-09-18

- First private experimental version.
- Consistent pass/fail/review contract, declarative policies and deterministic checks.
- OpenRouter and TypeSafe adapters, explicit offline provider, cost accounting and audit.
- Bounded repair loop, async interface and JSON CLI.
- Dev/dev-out bootstrap, tests, CI and manually triggered releases.
